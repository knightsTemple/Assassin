# 武器基类与装备加成

## 1. 当前实现及使用前提

本阶段建立武器数据与装备接口，不选择具体武器模型，不自动替换现有四段攻击动画。

已创建的内容目录：

```text
Content/AssassinGirl/Weapon/
├─ Sword/
├─ LongBlade/
├─ Bow/
├─ Shield/
└─ Axe/
```

C++ 新类需要手动编译并重新打开编辑器后才会出现。本次没有执行 C++ 编译、Live Coding 或显式蓝图编译，也尚未进行新 C++ 类的运行验证。

### 编译后创建蓝图

在 Unreal 的 Python 控制台运行：

```python
exec(open(r"F:/UEGame/Assassin/Docs/Tools/setup_weapon_assets.py", encoding="utf-8").read())
```

脚本检查原生类是否已加载；没有加载时只报告 `waiting_for_user_compile`，不会创建错误父类的替代蓝图。类加载后创建：

| 资产 | 父类 | 用途 |
| --- | --- | --- |
| `Weapon/BP_WeaponBase` | `AssassinWeaponBase` | 公共武器配置模板 |
| `Weapon/Sword/BP_SwordBase` | `BP_WeaponBase` | 剑配置模板 |
| `Weapon/LongBlade/BP_LongBladeBase` | `BP_WeaponBase` | 长刀配置模板 |
| `Weapon/Bow/BP_BowBase` | `BP_WeaponBase` | 弓箭配置模板 |
| `Weapon/Shield/BP_ShieldBase` | `AssassinShieldWeaponBase` | 盾牌配置模板 |
| `Weapon/Axe/BP_AxeBase` | `BP_WeaponBase` | 斧头配置模板 |
| `Weapon/GE_WeaponStats` | `AssassinWeaponStatsEffect` | 基础装备加成 GE |

盾牌原生类继承武器原生类，共享武器字段和同一份 Lua 逻辑；它不继承蓝图 `BP_WeaponBase` 的额外图表或蓝图专属默认值。

## 2. 各层负责什么

```text
武器 Blueprint：模型、数值、GE 列表、Socket、动画配置
            ↓
Weapon.WeaponBase.lua：装备、卸下、撤销加成、盾牌血量变化
            ↓
角色的 PlayerState ASC：保存装备贡献后的 GAS 属性
```

- **C++ 武器基类**：提供可序列化字段、组件和 UnLua 可调用接口。
- **Lua**：执行装备规则和生命周期，不在角色脚本中堆积不同武器的规则。
- **GE**：以独立效果句柄表示每件装备的贡献。卸下装备移除自己的句柄，避免通过“属性减回原数值”破坏其他 Buff。
- **Character / 装备管理器**：后续决定主武器、盾牌等槽位和切换顺序。武器 Actor 不自行选择或替换角色的其他装备。

## 3. 武器字段与单位

`AAssassinWeaponBase` 包含 `WeaponId`、`DisplayName`、`WeaponType` 和 `BaseStats`。

| 字段 | 含义 | 示例 |
| --- | --- | --- |
| `BaseStats.AttackPower` | 加到角色普通攻击力的值 | `20` = +20 攻击力 |
| `BaseStats.AssassinationPower` | 加到角色刺杀攻击力的值 | `30` = +30 刺杀攻击力 |
| `BaseStats.CritDamageBonus` | 暴击额外伤害倍率加成，沿用现有 AttributeSet 语义 | `0.5` = 额外 +50% |
| `BaseStats.CritChance` | 暴击概率加成，以 0～1 表示 | `0.1` = +10 个百分点 |
| `BaseStats.Weight` | 这件武器的重量 | `3` = 3 个项目约定的重量单位 |

这里的“暴击数值”暂按已有 `CritDamageBonus` 的**倍率**解释，不是固定伤害。最终伤害计算及概率上限仍由伤害系统负责。

属性集新增 `Weight`，表示当前装备重量的总贡献，并限制为非负值。重量暂不自动扣移速、攻速或耐力，避免在没有设计规则时添加隐藏惩罚。

## 4. Mesh 和挂接

- `WeaponRoot`：挂接角色的根组件。
- `WeaponMesh`：`StaticMeshComponent`。当前导入的武器是静态网格，直接在蓝图组件详情中选择 Static Mesh。
- `EquipSocketName`：装备时挂到角色骨骼网格的 Socket 或骨骼。可以选择实际存在的 `hand_r` 或自行建立握持 Socket。
- 模型朝向、握柄位置和缩放，在 `WeaponMesh` 的相对变换中调整。

默认关闭物理模拟和碰撞；命中判定以后使用攻击窗口内的 Trace，不把武器持续碰撞直接当成攻击。

`EquipSocketName=None` 时仅应用属性，方便先测加成；模型不会自动挂到角色身上。配置了 Socket 但角色没有这个 Socket 时装备失败。

当前接口挂接到握持位置。拔剑时从剑鞘换到手、收剑时换回剑鞘，需要在选定模型和 Socket 后接入动画通知；本阶段没有声称完成这部分视觉切换。

## 5. 基础加成 GE

原生 `UAssassinWeaponStatsEffect` 已包含六个 AddBase 修饰器。默认无限持续、不合并堆叠；武器装备时通过 SetByCaller 填入自己的数值。

| SetByCaller Tag | 目标属性 |
| --- | --- |
| `Assassin.Data.Equipment.AttackPower` | `AttackPower` |
| `Assassin.Data.Equipment.AssassinationPower` | `AssassinationPower` |
| `Assassin.Data.Equipment.CritDamageBonus` | `CritDamageBonus` |
| `Assassin.Data.Equipment.CritChance` | `CritChance` |
| `Assassin.Data.Equipment.Weight` | `Weight` |
| `Assassin.Data.Equipment.MaxHealth` | `MaxHealth` |

这些是原生 GameplayTag，由新模块加载时注册，不需要重复添加到 ini。普通武器的 `MaxHealth` 贡献为 0；盾牌通过派生类提供 `MaxHealthBonus`。

`EquipmentStatsEffectClass` 默认指向原生效果类，编译后即使尚未生成 GE 蓝图也有正确默认值。生成脚本将蓝图默认配置指向 `GE_WeaponStats`，便于在内容浏览器查看修饰器。

同一武器重复调用 `EquipToCharacter` 不重复添加 GE。每件武器只移除自己记录的效果句柄，不使用按 GE 类删除的方式。

## 6. 额外增益效果

`AdditionalEffects` 是 `GameplayEffect` **类**数组，可以配置攻击提升、移动速度提升等装备附加效果。

- 装备时对角色 ASC 应用；卸下时移除本件武器记录的句柄。
- 持续类型支持 **Infinite** 或 **HasDuration**。有限时长效果到期后自然结束，不会因其句柄已过期而阻止卸装。
- 不接受 **Instant**：Instant 修改无法通过移除活跃 GE 可靠撤销。拾取治疗或使用药品应走独立的使用效果接口。
- 当前要求 GE 使用 **None / No Stacking**，避免同类效果合并成共享句柄，卸下一个武器时误删除另一件装备的加成。
- 基础加成和额外 GE 分开配置；不要在额外 GE 中重复填写同一份攻击力，否则会叠加两次。
- 额外 GE 暂不接收自定义 SetByCaller 数据；它们可使用 GE 自身配置的常量或等级曲线。

若任意 GE 被条件拒绝或挂接失败，本次装备会回滚已添加的效果并返回 `false`。GE 回调不应另做无法撤销的奖励发放或永久改值。

## 7. 盾牌的两个生命概念

| 字段 | 所属对象 | 行为 |
| --- | --- | --- |
| `MaxShieldHealth` | 盾牌 Actor | 盾牌最大血量，默认 100，可配置 |
| `ShieldHealth` | 盾牌 Actor | 当前血量，开始游戏时初始化为最大值 |
| `MaxHealthBonus` | 装备者 | 通过基础 GE 增加角色最大生命值 |

- `ApplyShieldDamage(Damage)`：扣盾牌血量，返回实际扣除量，最低为 0。
- `RepairShield(Amount)`：修复盾牌，返回实际恢复量，最高不超过最大血量。
- `OnShieldHealthChanged`：提供 UI 或格挡反馈回调。
- 卸下再装备不会自动修满盾牌；重新生成一个 Actor 会初始化一件新盾牌。
- 盾牌血量归零目前只报告血量变化，不自动销毁盾牌，也不自动撤销装备加成。格挡、破盾和溢出伤害规则后续再接入。

生命值加成增加的是角色 **MaxHealth**，不自动增加或回复 **Health**。卸下盾牌后若当前生命超出新最大生命，已有 AttributeSet 会将当前生命限制到新的上限。

盾牌使用普通 Actor 字段存储自身血量，暂不为每件装备建立独立 ASC。角色生命与装备增益继续由角色 ASC 管理。

## 8. 调用接口

Lua 示例（已有武器实例和角色实例后）：

```lua
local Equipped = Weapon:EquipToCharacter(Character)
local Unequipped = Weapon:UnequipFromCharacter()

local LostShieldHealth = Shield:ApplyShieldDamage(30.0)
local RepairedShieldHealth = Shield:RepairShield(15.0)
```

装备和盾牌血量变化要求 Authority。本阶段面向当前单人原型，尚未实现武器 Actor 的联网复制或装备 RPC。

武器不能直接从一个角色转到另一个角色；先卸下，再装备给新角色。销毁已装备的武器时，Lua 的 EndPlay 会尝试移除它在 PlayerState ASC 上留下的效果。

## 9. 不同武器的动画配置

武器基类已预留 `LightAttackMontages`、`DrawMontage`、`SheatheMontage`。不同武器可以配置自己的动画，但当前 `AttackSystem` 尚未改为读取装备武器；其已有连击时序继续使用现有配置。

下一步先确定一把剑的模型、握持位置与收纳位置，再将角色当前武器和攻击动画路由接起来。武器动画切换时也要配套使用各自的连击时间配置，不能只替换 Montage 后沿用旧动作的时间点。

已在 UnLua 环境中用模拟 ASC 完成 36 项 Lua 逻辑断言，覆盖重复装备、武器与盾牌同时加成、卸装保持其他 Buff、装备失败回滚、盾牌扣血修复、销毁清理和错误 GE 配置拒绝。该检查验证 Lua 规则，不代替新 C++ 类与真实 GAS 的集成验证。

手动编译后的关键验收：

1. 能创建并打开武器/盾牌蓝图，能选择 Mesh 和各项属性。
2. 装备后属性增加，重复装备不叠加，卸下后恢复；其他 Buff 不被移除。
3. 同时装备武器和盾牌，卸下任一件只撤销对应贡献。
4. 额外 GE 有条件失败时，本次装备没有残留加成。

6. 销毁已装备的武器后 PlayerState ASC 没有残留的装备效果。

## 11. 武器等级与属性成长曲线

在 BP_Sword 的 Class Defaults 中设置：

- Weapon / Progression → 武器等级（WeaponLevel）：初始等级，最低为 1。
- 属性成长曲线（StatGrowthCurves）：攻击力、刺杀攻击力、暴击伤害倍率加成、暴击率、重量各一条 Curve Float。
- Weapon / Stats → BaseStats：未指定曲线的属性使用此处固定值；指定曲线后，该项使用曲线结果，不再额外加上 BaseStats。

BP_Sword 的五条曲线位于 `/Game/AssassinGirl/Weapon/Sword/Curves`。
横轴 Time 表示武器等级，纵轴 Value 表示该等级下武器提供的属性值。
例如攻击力曲线可设为 (1, 10)、(5, 30)、(10, 80)：1 级加 10 攻击力，5 级加 30，10 级加 80；中间等级按曲线插值。
这是配置示例，创建的曲线沿用了当前 BaseStats 的值（目前均为 0），没有套用示例平衡数值。
曲线的 1、10、20 级关键点可以在曲线编辑器中修改、增加或删除，CSV 初始源文件保存在 `Docs/Data/SwordCurves`。

暴击率使用小数：0.05 表示增加 5 个百分点；暴击伤害加成 0.5 表示增加 50%。
所有计算结果最低为 0，武器暴击率加成最多为 1。
超出曲线关键点范围时遵循 Curve Float 的外推设置；默认保持端点值。
重量也可以使用固定曲线，或不指定曲线以保持 BaseStats 的重量。

运行时对**武器实例**调用：

```lua
local Success = Sword:SetWeaponLevel(5)
local CurrentStats = Sword:GetCurrentStats()
local PreviewAtTen = Sword:GetStatsAtLevel(10)
```

这些接口也可在蓝图中调用。等级计算及装备刷新规则实现在 Weapon.WeaponBase.lua，BP_Sword.lua 继承这些规则。
运行时改等级应调用 SetWeaponLevel，不要直接赋值 WeaponLevel。
成功升级会更新该武器已经施加的基础 GE 的 SetByCaller 值，不重复施加 GE，也不重置 AdditionalEffects 的持续时间。
如果武器尚未装备，只更新等级，下一次装备时使用新等级的属性。
如果武器的基础 GE 已被外部移除，刷新返回 false，SetWeaponLevel 保留原等级；可卸下后重新装备恢复。
改动 BaseStats 或成长曲线后，对已装备实例调用 RefreshEquipmentStats 可立即刷新。

WeaponLevel 与原有 EffectLevel 不同：前者用于曲线采样，后者仍是创建 GE Spec 时的效果等级。
GE_SwordStats 继续采用 Infinite + SetByCaller；不需要在 GE 的 Modifier 中重复填写曲线数值。
